# Postman CRUD Calls - 2025-06-30

This note summarizes how the five basic FHIR Patient CRUD calls were executed in Postman and how they can be mirrored using cURL commands.

## CRUD Calls

1. **Create Patient**
   - Postman Request: POST `{{baseUrl}}/Patient`
   - Sample Body: `{"resourceType": "Patient", "id": "123"}`
   - Equivalent cURL:
     ```
     curl -X POST {{baseUrl}}/Patient \
       -H "Content-Type: application/fhir+json" \
       -d @patient.json
     ```

2. **Read Patient**
   - Postman Request: GET `{{baseUrl}}/Patient/123`
   - Equivalent cURL: `curl -X GET {{baseUrl}}/Patient/123`

3. **Update Patient**
   - Postman Request: PUT `{{baseUrl}}/Patient/123`
   - Equivalent cURL:
     ```
     curl -X PUT {{baseUrl}}/Patient/123 \
       -H "Content-Type: application/fhir+json" \
       -d @updated_patient.json
     ```

4. **Patch Patient**
   - Postman Request: PATCH `{{baseUrl}}/Patient/123`
   - Equivalent cURL:
     ```
     curl -X PATCH {{baseUrl}}/Patient/123 \
       -H "Content-Type: application/json-patch+json" \
       -d @patch.json
     ```

5. **Delete Patient**
   - Postman Request: DELETE `{{baseUrl}}/Patient/123`
   - Equivalent cURL: `curl -X DELETE {{baseUrl}}/Patient/123`

## Reflections

Using Postman helped verify each FHIR interaction with a clean UI and environment variables. Translating the same requests to cURL made it easier to automate the calls in scripts or notebooks. Both approaches complement each other during development.
